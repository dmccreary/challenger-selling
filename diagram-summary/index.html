    Diagram Summary¶

    This document provides a comprehensive summary of all interactive diagrams and visualizations in the Challenger Selling textbook.

    Total Diagram Count¶

    49 interactive diagram specifications + 1 Mermaid flowchart = 50 total diagrams

    Diagrams by Chapter¶

    Chapter 1: Challenger Sales Methodology & Insights (5 diagrams)¶

    1. Challenger Principles Explorer - Interactive exploration of the three Challenger principles (teach, tailor, take control)
    2. Sales Profiles Comparison - Compare the five sales profiles (Challenger, Teacher, Relationship Builder, Problem Solver, Lone Wolf)
    3. Stakeholder Mapping Tool - Map stakeholders and their priorities for a sales opportunity
    4. Customer Priority Map Builder - Build a visual map of competing customer priorities
    5. Insight Type Selector - Select and apply different insight types (Warmer, Rational Drowning, Rock Star)

    Chapter 2: Storytelling Fundamentals & Psychology (4 diagrams)¶

    1. Hero's Journey Interactive Map - Interactive map of the Hero's Journey story structure
    2. Story Arc Builder - Build stories using different story arc patterns
    3. Memory Retention Experiment - Experiment with memory retention through storytelling
    4. Cognitive Bias Simulator - Explore how cognitive biases affect decision-making

    Chapter 3: Buyer Personas & Industry Segmentation (2 diagrams)¶

    1. Persona Matcher - Match stories to different buyer personas
    2. Vertical Insight Tailorer - Tailor insights for different industry verticals

    Chapter 4: Objection Handling & Story Portfolio (2 diagrams)¶

    1. Story Component Builder - Build stories using the six-component structure
    2. Objection Story Selector - Select appropriate stories for handling objections

    Chapter 5: AI-Assisted Story Generation & Agents (2 diagrams)¶

    1. Prompt Engineering Workshop - Practice prompt engineering for AI story generation
    2. Dialogue Flow Designer - Design dialogue flows for conversational AI agents

    Chapter 6: Graph Database Fundamentals & Sales Stories (3 diagrams)¶

    1. Graph Data Model Visualizer - Visualize graph data models for sales stories
    2. Graph Traversal Explorer - Explore graph traversal patterns
    3. Use Case Matcher - Match graph database use cases to sales scenarios

    Chapter 7: AI Framework Fundamentals & Sales Stories (1 diagram)¶

    1. Framework Comparison Chart - Compare ML frameworks (TensorFlow, PyTorch, scikit-learn)

    Chapter 8: Intelligent Textbook Tools & Sales Stories (4 diagrams)¶

    1. Adaptive Learning Path Designer - Design adaptive learning paths based on learner performance
    2. xAPI Statement Builder - Build xAPI statements for learning analytics
    3. MicroSim Type Explorer - Explore different types of MicroSims (p5.js, Chart.js, vis-network, etc.)
    4. Learning Graph Visualizer - Visualize concept dependencies in the learning graph

    Chapter 9: Story Effectiveness & Analytics (2 diagrams)¶

    1. Metrics Selector - Select appropriate metrics for measuring story effectiveness
    2. A/B Test Designer - Design A/B tests for comparing story versions

    Chapter 10: Story Delivery, Integration & Coaching (4 diagrams)¶

    1. Insight Personalizer - Personalize Challenger insights for different customers
    2. Channel Story Adapter - Adapt stories for different delivery channels
    3. Integration Architect - Design story integration with CRM and sales enablement platforms
    4. Training Program Designer - Design training programs for story delivery coaching

    Chapter 11: Story Libraries, Customization & Trust (4 diagrams)¶

    1. Story Library Organizer - Organize stories by type (industry, persona, objection, stage, product)
    2. Industry Story Translator - Adapt stories for different industries
    3. Story Customizer - Customize stories for specific customers and contexts
    4. Trust Story Selector - Select trust-building stories (credibility, authority, vulnerability, authenticity)

    Chapter 12: Story Creation & Templates (4 diagrams)¶

    1. Story Process Flow - Design the story creation process flow
    2. Story Draft Builder - Build story drafts using component structure
    3. Story Tester - Test stories against quality criteria
    4. Template Component Assembler - Assemble stories from modular template components

    Chapter 13: Story Innovation, Strategy & Crisis (3 diagrams)¶

    1. Story Innovation Explorer - Explore innovative storytelling approaches
    2. Brand Alignment Checker - Evaluate stories for brand alignment
    3. Crisis Response Simulator - Simulate crisis response storytelling

    Chapter 14: Story Planning, Metrics & Alignment (3 diagrams)¶

    1. Metrics Cascade Designer - Design metrics cascading from business objectives to KPIs
    2. Strategic Alignment Mapper - Map storytelling initiatives to business strategy
    3. ROI Calculator - Calculate ROI for storytelling initiatives

    Chapter 15: Story Architecture, DevOps & Testing (3 diagrams)¶

    1. Architecture Layer Designer - Design storytelling system architecture layers
    2. CI/CD Pipeline Builder - Build CI/CD pipelines for storytelling systems
    3. Testing Strategy Selector - Select appropriate testing types for storytelling systems

    Chapter 16: Advanced AI & Immersive Experiences (3 diagrams)¶

    1. AI Capability Selector - Select AI capabilities (NLP, Speech Recognition, Sentiment AI, Emotion AI)
    2. Immersive Experience Designer - Design immersive experiences (VR, AR, MR)
    3. Sentiment Analyzer - Analyze sentiment in story excerpts and customer responses

    Chapter 17: Capstone Project (1 diagram)¶

    1. Capstone Project Flow (Mermaid flowchart) - Visualizes the sequential steps of the capstone project from customer analysis through final deliverables

    Diagram Types¶

    • Interactive Infographics (46) - Most diagrams are interactive infographics with user selections, feedback, and learning activities
    • Mermaid Flowchart (1) - The capstone project uses a Mermaid flowchart for process visualization
    • Charts/Comparisons (3) - Framework comparison and visualization tools

    Bloom's Taxonomy Distribution¶

    Most diagrams target these Bloom's Taxonomy levels: - Apply - Select, design, build, calculate, map, adapt - Evaluate - Analyze, assess, test, check - Create - Innovate, design, generate

    Learning Objectives¶

    All diagrams are designed to: - Support understanding of key concepts - Provide interactive practice opportunities - Gather learner interaction data for assessment - Deliver immediate feedback on learner choices - Connect theory to practical application

    Implementation Status¶

    All 49 diagram specifications are written in markdown using the #### Diagram: heading format. These specifications are ready for implementation as interactive MicroSims using the microsim-generator skill.

    The Mermaid flowchart in Chapter 17 is currently functional and renders as an interactive diagram.
