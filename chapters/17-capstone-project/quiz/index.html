    Quiz: Capstone Project¶

    Test your understanding of the capstone project structure, deliverables, evaluation criteria, and integrated application of Challenger Selling concepts with these 10 review questions.

    1. What product or solution is the capstone project focused on selling?¶

    1. A graph database platform
    2. An AI machine learning framework
    3. An intelligent textbook generation platform
    4. A customer relationship management system
    Show Answer

    The correct answer is C. The capstone requires designing a sales strategy for an intelligent textbook generation platform sold to a university or corporate training department. The other products are covered in earlier chapters but are not the capstone focus.

    Concept Tested: Capstone Project

    2. According to the project requirements, how many key metrics should the analytics framework define?¶

    1. 5-7
    2. 2-3
    3. 10-12
    4. Exactly 1
    Show Answer

    The correct answer is A. The capstone analytics framework asks for 5-7 key metrics that include both leading indicators such as engagement and lagging indicators such as conversion and revenue.

    Concept Tested: Capstone Project

    3. Why should the analytics framework include both leading and lagging indicators?¶

    1. Leading indicators show early signals while lagging indicators confirm final outcomes
    2. It makes the framework longer and more impressive
    3. Executives only care about lagging indicators
    4. It reduces the number of metrics needed
    Show Answer

    The correct answer is D. Leading indicators like engagement and story recall provide early feedback, while lagging indicators like win rate and revenue confirm business impact. A balanced framework needs both to guide decisions and prove value.

    Concept Tested: Capstone Project

    4. What is the primary focus of Phase 1 (Months 1-2) in the implementation roadmap?¶

    1. AI augmentation and advanced personalization
    2. A/B testing and analytics refinement
    3. Story library creation, CRM integration, and initial training
    4. Continuous improvement at scale
    Show Answer

    The correct answer is C. Phase 1 builds the foundation: creating the story library, integrating it into CRM, and training the sales team. AI augmentation and scaling come in later phases.

    Concept Tested: Capstone Project

    5. When adapting the core Challenger insight story for a CFO stakeholder in the capstone, which emphasis is most appropriate?¶

    1. Student engagement and faculty enthusiasm
    2. Financial return, cost reduction, and ROI
    3. API architecture and developer tooling
    4. Technical implementation details
    Show Answer

    The correct answer is A. CFOs prioritize financial impact, so the insight should be tailored to cost savings, ROI, and risk. Engagement and architecture matter to other stakeholders.

    Concept Tested: Capstone Project

    6. A capstone insight is described in generic terms without specific industry or customer context. Which evaluation criterion is most likely weak?¶

    1. AI Application
    2. Insight Quality
    3. Strategy Completeness
    4. Project length
    Show Answer

    The correct answer is B. Insight Quality requires that the Challenger insight be specific, data-supported, and effectively reframe the customer's thinking. Generic insights fail to demonstrate disruption and relevance to the chosen customer.

    Concept Tested: Capstone Project

    7. A capstone proposal recommends using AI-generated stories without any human review or verification. Which evaluation criterion does this most directly threaten?¶

    1. Concept Integration
    2. AI Application
    3. Story Quality
    4. All of the above
    Show Answer

    The correct answer is D. Using unreviewed AI content threatens AI Application (must enhance rather than replace human judgment), Story Quality (risks inaccuracies), and Concept Integration (ignores human-AI collaboration principles). All criteria are relevant.

    Concept Tested: Capstone Project

    8. Which deliverable most directly demonstrates whether the capstone strategy is realistic and executable?¶

    1. Executive Summary
    2. Implementation Roadmap
    3. Appendices
    4. Persona Profiles
    Show Answer

    The correct answer is B. The Implementation Roadmap defines phases, activities, milestones, and success criteria, making the strategy actionable. The executive summary provides overview, appendices provide detail, and personas inform tailoring but do not show execution planning.

    Concept Tested: Capstone Project

    9. A Customer Priority Map in the capstone helps the sales team:¶

    1. Tailor the insight to stakeholders with competing priorities
    2. Design graphics for the story library
    3. Select the underlying AI model
    4. Write software code for integration
    Show Answer

    The correct answer is A. The Customer Priority Map reveals how stakeholders rank competing concerns, enabling the team to tailor the Challenger insight and anticipate tension points. It does not guide graphic design, AI model selection, or coding.

    Concept Tested: Capstone Project

    10. To improve the quality of capstone stories before final submission, which action is most effective?¶

    1. Generate more stories with AI to increase volume
    2. Test stories with friendly customers or salespeople and refine based on feedback
    3. Add more stories without reviewing existing ones
    4. Remove calls to action to keep stories shorter
    Show Answer

    The correct answer is B. Testing and refining stories with real feedback improves clarity, relevance, and effectiveness. Adding volume without review, removing calls to action, or relying solely on AI generation would reduce story quality.
