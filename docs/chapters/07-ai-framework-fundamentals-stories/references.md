# References: AI Framework Fundamentals & Sales Stories

1. [TensorFlow](https://en.wikipedia.org/wiki/TensorFlow) - Wikipedia - Google's open-source machine-learning framework, its ecosystem, and production-deployment strengths.

2. [PyTorch](https://en.wikipedia.org/wiki/PyTorch) - Wikipedia - Facebook's dynamic deep-learning framework, its research popularity, and ease-of-use features.

3. [Scikit-learn](https://en.wikipedia.org/wiki/Scikit-learn) - Wikipedia - Python library for traditional machine learning, covering classification, regression, clustering, and model evaluation.

4. *Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow* - Aurélien Géron - O'Reilly Media - Géron's widely adopted book provides a clear, practical path from Scikit-learn fundamentals to TensorFlow/Keras deep learning.

5. *Deep Learning* - Ian Goodfellow, Yoshua Bengio, and Aaron Courville - MIT Press - Goodfellow, Bengio, and Courville co-authored the standard graduate reference for neural-network theory and frameworks.

6. [TensorFlow.org Tutorials](https://www.tensorflow.org/tutorials) - TensorFlow - Official beginner-to-advanced tutorials covering model building, training, and deployment.

7. [PyTorch Tutorials](https://pytorch.org/tutorials/) - PyTorch - Official tutorials for tensors, autograd, neural networks, and production deployment with TorchServe.

8. [Scikit-learn User Guide](https://scikit-learn.org/stable/user_guide.html) - Scikit-learn - Comprehensive documentation with examples for supervised and unsupervised learning workflows.

9. [fast.ai: Practical Deep Learning for Coders](https://course.fast.ai/) - fast.ai - Free course that teaches applied deep learning and PyTorch with a focus on rapid prototyping and real-world use cases.

10. [Kaggle: Machine Learning Courses](https://www.kaggle.com/learn) - Kaggle - Short, hands-on micro-courses on Python, ML, deep learning, and model deployment.
