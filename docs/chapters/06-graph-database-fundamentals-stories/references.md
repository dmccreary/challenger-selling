# References: Graph Database Fundamentals & Sales Stories

1. [Graph Database](https://en.wikipedia.org/wiki/Graph_database) - Wikipedia - Explains property-graph and RDF models, use cases, and performance advantages for connected-data problems.

2. [Neo4j](https://en.wikipedia.org/wiki/Neo4j) - Wikipedia - Overview of the leading property-graph database, its data model, query language, and enterprise applications.

3. [Cypher Query Language](https://en.wikipedia.org/wiki/Cypher_(query_language)) - Wikipedia - Declarative graph query language syntax, pattern matching, and relationship traversal basics.

4. *Graph Databases* - Ian Robinson, Jim Webber, and Emil Eifrem - O'Reilly Media - Robinson, Webber, and Eifrem wrote the definitive practical guide to graph data modeling, Cypher, and connected-data thinking.

5. *Learning Neo4j 3.x* - Rik Van Brugman and Ivan Zoratti - Packt Publishing - A hands-on, example-driven introduction to graph database concepts and Neo4j implementation for real-world projects.

6. [Neo4j GraphAcademy](https://graphacademy.neo4j.com/) - Neo4j - Free, self-paced courses on graph data modeling, Cypher, and building graph-powered applications.

7. [Neo4j Documentation](https://neo4j.com/docs/) - Neo4j - Official reference for Cypher, drivers, deployment, and performance tuning.

8. [Amazon Neptune: Graph Database Use Cases](https://aws.amazon.com/neptune/use-cases/) - AWS - Overview of knowledge graphs, fraud detection, recommendation engines, and network analytics on a managed graph database.

9. [Microsoft Azure Cosmos DB Gremlin](https://learn.microsoft.com/en-us/azure/cosmos-db/gremlin/) - Microsoft Learn - Tutorial on graph traversal with Gremlin in Azure Cosmos DB.

10. [DataStax: Graph Database Use Cases](https://www.datastax.com/learn/data-modeling/graph-data-modeling) - DataStax - Practical guidance on graph data modeling, traversals, and choosing graph over relational databases.
