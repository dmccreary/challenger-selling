## About This MicroSim

Different kinds of testing catch different defects. **Unit tests** check one component in isolation. **Integration tests** check that components and systems exchange data correctly. **System tests** run the entire workflow end to end. **User acceptance testing (UAT)** has real users confirm the system works for their actual tasks.

This MicroSim gives you four scenarios from a storytelling platform and asks you to choose the testing type for each. A reference line at the top shows the four levels from smallest to largest, and feedback explains what each type is designed to catch.

**Learning objective (Apply, *select*):** Select appropriate testing types (unit, integration, system, UAT) for different testing scenarios and objectives.

## How to Use

1. Read the testing scenario.
2. Choose one of the four **Testing Type** buttons.
3. Select **Submit** for feedback. You can resubmit; only your first try counts.
4. Select **Next Scenario**. After all four, the summary lists each scenario and its testing type.

## Lesson Plan

### Audience
Sales professionals, account executives, sales engineers and business development managers.

### Duration
8 minutes

### Prerequisites
- Story Testing Strategy and Story Quality Assurance sections of Chapter 15

### Activities

1. **Matching** (4 min): Complete all four scenarios and record your first-try score.
2. **Reasoning** (2 min): Give an example of a defect that passes every unit test but fails integration testing.
3. **Transfer** (2 min): Who should take part in UAT for a new story platform at your company?

### Common Misconceptions
- All testing is the same.
- Unit testing is sufficient.
- UAT is optional.

### Assessment
- Correct testing type for all four scenarios.
- Learner can explain why UAT is not optional.
