## About This MicroSim

MicroSims are small interactive simulations embedded in an intelligent textbook. They come in several types, and each fits a different kind of learning: manipulating a system, comparing data, exploring connections, tracing feedback loops, or sorting concepts into categories.

This MicroSim presents five learning needs. For each one you pick the MicroSim type that serves it best. Feedback explains what each type is built for. The same thinking applies when you design interactive sales content: choose the format by asking what the learner, or the buyer, must *do*.

**Learning objective (Understand, *identify*):** Identify different types of MicroSims (p5.js, Chart.js, vis-network, causal-loop, concept-classifier) and their appropriate use cases.

## How to Use

1. Read the learning need.
2. Choose one of the five **MicroSim Type** buttons.
3. Select **Submit** for feedback. You can resubmit; only the first try counts.
4. Select **Next Scenario**. After all five, the summary lists each type and its use.

## Lesson Plan

### Audience
Sales professionals, account executives, sales engineers and business development managers.

### Duration
8 minutes

### Prerequisites
- MicroSims section of Chapter 8

### Activities

1. **Matching** (4 min): Complete all five scenarios and record your first-try score.
2. **Comparison** (2 min): vis-network and causal-loop both draw nodes and arrows. What does a causal-loop diagram add?
3. **Transfer** (2 min): Pick one concept from this book and name the MicroSim type you would build for it.

### Common Misconceptions
- All MicroSims are the same.
- Any MicroSim type works for any concept.
- MicroSims are just visualizations.

### Assessment
- Correct type for all five scenarios.
- Learner can explain the difference between a network diagram and a causal-loop diagram.
