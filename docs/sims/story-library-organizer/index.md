## About This MicroSim

A story library is only useful if reps can find the right story in seconds. That depends on **tagging**: labeling every story on the same dimensions so it can be retrieved from many different searches.

In this MicroSim you tag six stories on five dimensions: industry, persona, objection, deal stage, and product. Each story says when reps use it, which tells you the objection and stage. After each submission the story appears as a library card listing every search that will now find it. Several stories share tags, which shows that tags are not exclusive categories.

**Learning objective (Apply, *organize*):** Organize a story library by categorizing stories according to different dimensions (industry, persona, objection, stage, product).

## How to Use

1. Read the story and the sentence describing when reps use it.
2. Choose a value for each of the five dimensions.
3. Select **Submit** to see the library card and feedback. You can resubmit; only your first try counts.
4. Select **Next Story**. After all six, the summary shows the organized library.

## Lesson Plan

### Audience
Sales professionals, account executives, sales engineers and business development managers.

### Duration
12 minutes

### Prerequisites
- Story Libraries, Industry-Specific Stories, and Persona-Specific Stories sections of Chapter 11

### Activities

1. **Tagging** (7 min): Tag all six stories and record your first-try score.
2. **Retrieval** (2 min): Using the summary, find the story you would use for a late-stage price objection from a CFO.
3. **Transfer** (3 min): Tag one story your team tells today on all five dimensions.

### Common Misconceptions
- Stories fit only one category.
- Categorization is optional.
- All dimensions are equally important.

### Assessment
- All five tags correct for all six stories.
- Learner can explain why one story can carry several tags.
